# Revista de Coches

Web de noticias y catálogo de coches hecha con HTML, CSS, PHP y MySQL.

## Funciones
- Portada con las últimas noticias
- Catálogo de coches con filtro por marca
- Páginas por categoría
- Panel de administración con login (crear, editar y borrar noticias y coches)

## Cómo probarlo en local
1. Instala XAMPP e inicia Apache y MySQL.
2. Copia el proyecto en `htdocs`.
3. Importa `sql/revista_coches.sql` desde phpMyAdmin.
4. Copia `config/conexion.ejemplo.php` como `config/conexion.php` y pon tu contraseña.
